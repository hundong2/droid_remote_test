📡 API 엔드포인트 (14 endpoints)

  Device Management:
    GET    /devices                          - List devices
    GET    /devices/{serial}/properties      - Get properties

  Logcat:
    WS     /logcat/{serial}                  - Stream logs
    GET    /logcat/{serial}/recent           - Recent logs
    POST   /logcat/{serial}/clear            - Clear logs

  Command Execution:
    POST   /command/{serial}                 - Execute command
    POST   /command/{serial}/install         - Install APK
    POST   /command/{serial}/uninstall       - Uninstall app
    POST   /command/{serial}/reboot          - Reboot device
    GET    /command/{serial}/screen          - Screen info
    POST   /command/{serial}/input           - Text input
    POST   /command/{serial}/tap             - Tap screen
    POST   /command/{serial}/swipe           - Swipe gesture
    POST   /command/{serial}/keyevent        - Key event

🚀 Quick Start

  1. Build:
     ./gradlew build

  2. Run:
     ./gradlew run

  3. Test:
     curl http://localhost:8080/
     curl http://localhost:8080/devices

  4. WebSocket (JavaScript):
     const ws = new WebSocket('ws://localhost:8080/logcat/SERIAL');
     ws.onmessage = (e) => console.log(e.data);
